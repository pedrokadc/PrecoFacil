# PrecoFacil
Startup de precificação local

Façam Commit e Push apenas quando terminarem a alteração. Se quiserem ir salvando durante o processo, podem fazer vários commits, mas lembrem de separar cada um com nomes do que foi feito.

- **Git: Clone** — Baixa o projeto do GitHub para o seu computador.
- **Git: Pull** — Baixa as atualizações que o pessoal já subiu para a sua máquina.
- **Git: Create Branch** — Cria uma ramificação nova para você desenvolver algo separado sem mexer no código principal.
- **Git: Checkout to** — Troca entre as branches que já existem.
- **Git: Commit** — Salva suas alterações no seu computador (sempre coloque o nome do que mudou).
- **Git: Push** — Envia seus commits para o GitHub, atualizando o projeto para todo mundo.
- **GitHub: Publish to GitHub** — Sobe um projeto novo do seu PC para o GitHub pela primeira vez.
